# 🚀 VibeOps Masterclass Hub (AIOps, MLOps, FinOps, Team Topologies, FDE & SRE)

A comprehensive, production-grade interactive masterclass portal, operational simulator, and template library built for modern AI, Cloud, Systems, and Reliability Engineers.

![VibeOps Masterclass Hub](src/assets/hero.png)

## 🌐 Features & Capabilities

### 1. ⚡ The Triad Matrix & Deep Dives
- **AIOps (AI for IT Operations)**: Noise reduction, OpenTelemetry tracing, Z-Score anomaly math, GNN root cause analysis, and automated self-healing runbooks.
- **MLOps (Machine Learning Operations)**: Feature Stores (Feast), Population Stability Index (PSI) data drift, LLM GPU VRAM math, RAG triad faithfulness metrics, and vLLM inference serving.
- **FinOps (Cloud & AI Financial Operations)**: FOCUS 1.0 specification SQL cost allocation, Redis semantic prompt caching ROI, Kubecost pod allocation, and Infracost CI/CD pull request blockers.

### 2. 👥 Human Systems & Engineering Operating System
- **Team Topologies (Layman's Guide)**: Layman's kitchen analogy, Conway's Law, Cognitive Load Theory (Intrinsic, Extraneous, Germane), and 4 core team types (Stream-Aligned, Platform, Enabling, Complicated-Subsystem).
- **Forward Deployed Engineer (FDE)**: 10-point self-assessment diagnostic, 4-stage technical learning roadmap, portfolio projects, stakeholder delivery frameworks, and transition pathways (from SWE, Solutions Architect, Data Engineer).
- **Site Reliability Engineer (SRE)**: 10-point self-assessment diagnostic, 4-stage technical roadmap, Linux eBPF/strace kernel commands, SLO/SLI error budget burn-rate simulator, and Google-style post-mortem guide.

### 3. 🚨 Interactive Operational Simulators
- **SRE On-Call Incident Simulator**: Triage live P0 outages with real CLI logs (`kubectl`, `strace`, `git log`), choose mitigation actions, and receive instant performance grading (Grade A+ to F).
- **FinOps Cloud Waste Hunter Game**: Audit a simulated $150k/mo cloud invoice, eliminate idle GPUs/disks, and calculate live annual savings.
- **FDE Client Security Crisis Challenge**: Navigate air-gapped security compliance under deadline pressure.

### 4. 📋 Production Copy-Paste Template Repository
- `otel-collector-config.yaml`
- `prometheus-burnrate-alert.yaml`
- `focus-cost-allocation.sql`
- `blameless-postmortem-template.md`
- `fde-technical-architecture-spec.md`

### 5. 🔍 Live Search & Persona Adaptor Engine
- Instant real-time keyword search across all models, code snippets, metrics, and templates.
- Persona-tailored views for **SRE / DevOps**, **ML / Data Scientist**, **FinOps Specialist**, and **CTO / Executive**.

## 🛠️ Local Development & Deployment

### Prerequisites
- Node.js (v18+ recommended)
- npm / yarn / pnpm

### Quick Start
```bash
# Clone the repository
git clone https://github.com/santoshadkar/AIMLFINOps-SRE-FDE-Masterhub.git

# Navigate into project directory
cd AIMLFINOps-SRE-FDE-Masterhub

# Install dependencies
npm install

# Start Vite local development server
npm run dev
```

Open your browser at `http://localhost:5173/`.

### Production Build
```bash
npm run build
```
