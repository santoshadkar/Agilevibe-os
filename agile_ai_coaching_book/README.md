## 🖥️ Interactive Web Portal

This repository includes a modern React web application located in `web_portal/`. It provides:
- Complete readable book content with interactive table of contents.
- Interactive Prompt Studio (search & copy 100+ prompts).
- JQL / WIQL query builder & cheatsheet explorer.
- AI Agile Coaching Assistant simulator.

To start the portal locally:
```bash
cd web_portal
npm install
npm run dev
```
