## 🚀 Live Demo & Local Deployment

### Direct Browser Access:
Simply open `index.html` in any web browser!

### Running via Python HTTP Server:
```bash
# Clone the repository
git clone https://github.com/santoshadkar/AI-LEADER-MASTERCLASS.git
cd AI-LEADER-MASTERCLASS

# Launch local HTTP web server
python -m http.server 8085 --bind 127.0.0.1
```
Open **[http://127.0.0.1:8085](http://127.0.0.1:8085)** in your browser.

## 🌐 Deploy to GitHub Pages (1-Click Hosting)

1. Go to your repository settings on GitHub: `https://github.com/santoshadkar/AI-LEADER-MASTERCLASS/settings/pages`
2. Under **Build and deployment** ➔ **Source**, select **Deploy from a branch**.
3. Choose Branch `main` and Folder `/ (root)`.
4. Click **Save**. Your portal will be live globally in 60 seconds at `https://santoshadkar.github.io/AI-LEADER-MASTERCLASS/`!
